# Dxkabegami - 4D水中壁紙

デリーシャスな壁紙 - リアルな水面と泳ぐ魚の立体映像

## 特徴

🌊 **リアルな水面効果**
- スマホの表面が水面のように見えるリアルな立体映像
- 波の動きと光の反射をシミュレーション
- Three.jsベースの高品質な3Dレンダリング

🐠 **水中で泳ぐ魚**
- 15匹の魚が自然に泳ぎ回る
- それぞれ異なる色と動きのパターン
- リアルな尾びれの動き

💧 **インタラクティブな水しぶき**
- 画面をタップすると水しぶきが発生
- 美しい波紋エフェクト
- タッチに反応するリアルタイムシミュレーション

## 使い方

### ウェブブラウザで開く

1. `index.html` をウェブブラウザで開く
2. 画面をクリックまたはタップして水面に触れる
3. 水しぶきと波紋を楽しむ

### ローカルサーバーで実行（推奨）

```bash
# Python 3がインストールされている場合
python3 -m http.server 8000

# Node.jsがインストールされている場合
npx http-server
```

ブラウザで `http://localhost:8000` を開く

### モバイルデバイスでの使用

1. ウェブサーバーでホストする
2. モバイルブラウザでアクセス
3. 全画面モードで表示
4. ホーム画面に追加してアプリのように使用

## 技術仕様

- **Three.js r128**: 3Dグラフィックスライブラリ
- **カスタムシェーダー**: 水面のリアルタイムシミュレーション
- **パーティクルシステム**: 水しぶきエフェクト
- **レスポンシブデザイン**: モバイルとデスクトップに対応

## ブラウザ互換性

- Chrome/Edge (推奨)
- Firefox
- Safari (iOS/macOS)
- モバイルブラウザ全般
